# Munger mental models

Interpretation of Charlie Munger's documented method. It challenges theses; it
does not originate buy recommendations or set prices.

## When to use

- Before committing: invert the thesis, check incentives, confirm the circle.
- When a story feels persuasive but the numbers are thin.
- When psychology (envy, action bias, ideology, self-pity) may be driving.
- As a pre-decision checklist gate alongside any other framework.

## Inputs required

- The thesis in one paragraph + the key numbers behind it.
- Incentive map: management, sellers, advisors, and your own incentives.
- The "too-hard" test: what must be understood, and is it understood from filed
  evidence? Otherwise `insufficient-evidence`.

## Workflow

1. State the thesis, then **invert**: list everything that would guarantee
   failure/ruin here, and design each out or stop (MUN-P02).
2. Map incentives (MUN-P03) — including yours. If the incentives predict the
   behavior you are betting against, downgrade or stop.
3. Check the circle (MUN-P04): edge or no edge? Too-hard pile is a valid output.
4. Run the odds (MUN-P05): base rates, decision tree, what is priced in.
5. Apply temperament + checklist (MUN-P06, MUN-P07, MUN-P08): envy/ideology
   screen, disconfirmation hunt, lollapalooza check.
6. Record every step; keep the analysis inspectable for the router.

## Output contract

- For each principle: verdict, supporting/disconfirming evidence with source
  IDs, invalidation conditions. Label statements **Documented principle**,
  **Interpretation**, or **Implementation choice**.
- End with: proceed / proceed-with-conditions / too-hard / reject, plus what
  evidence would change it.

## Limitations

- Base rates, Kelly-style sizing, and "outside view" language are later glosses,
  not Munger's terms — never attribute them to him.
- Wesco/Daily Journal attendee notes are reconstructions (labeled in sources).
- Temperament is not codifiable into a score; this skill checks process, not
  character.
