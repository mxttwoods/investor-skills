# Router — worked example (short trace)

Question: "A wide-moat compounder fell 25% on a guidance cut; operating
margins intact, balance sheet clean. Buy?"

1. Identify: single-stock quality decision, 3–5 yr horizon, mandate long-only.
   Tactical timing explicitly out of scope for the buy verdict.
2. Select: Buffett (patience/quality), Munger (inversion/incentives),
   Lynch (category + story recheck), Marks (expectations reset), shared
   discipline. Druckenmiller off (no regime question); Nomad on only if
   shared-scale evidence exists — here, off with reason recorded.
3. Inspectable runs: BUF-P01/P03–P05 (operating intact → patience candidate);
   MUN-P02/P03 (ruin paths: leverage/fraud/dilution — none evidenced);
   LYN-P01/P02/P08 (stalwart; story rechecked; solvency clean);
   MRK-P02/P04 (expectations reset lower — the actual opportunity).
4. Disagreement: none material; tactical entry timing left open with a
   separate stop/review rule rather than a quality-derived entry.
5. Synthesis: worthy-of-deep-dive; invalidation = next two quarters' margins;
   missing = customer-concentration + insider-buying records.
