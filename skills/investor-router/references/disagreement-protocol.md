# Router — disagreement protocol

For every material disagreement, report all five (no vote, no average, no
famous-name count; Buffett/Munger/Nomad never independent witnesses):

1. Competing conclusions (one sentence each, with principle IDs).
2. Assumptions driving the difference (numbered, testable).
3. Relevant time horizons (e.g. 3–5 yr quality vs 3–6 mo tactical).
4. Evidence each framework emphasizes (with source IDs).
5. What additional information could resolve it (ranked by decision value).

Template:

- Position A (skill/principles): …
- Position B (skill/principles): …
- Driving assumptions: (a) … (b) …
- Horizons: A … vs B …
- Emphasized evidence: A … / B …
- Would resolve: 1) … 2) …
- Synthesis to mandate: … (or preserved disagreement + next evidence to get)
